# 🐾 HuellasIA

## Objetivo

HuellasIA es una aplicación que conecta personas que perdieron sus mascotas con quienes las encontraron mediante reconocimiento de imágenes utilizando Inteligencia Artificial.

## Funciones principales

- Registro de usuarios
- Inicio de sesión
- Publicar mascotas perdidas
- Publicar mascotas encontradas
- Reconocimiento mediante IA
- Mapa de ubicaciones
- Notificaciones
- Chat entre usuarios

## Tecnologías

### Frontend
- Flutter

### Backend
- FastAPI

### Base de datos
- PostgreSQL

### Inteligencia Artificial
- PyTorch
- OpenCV
