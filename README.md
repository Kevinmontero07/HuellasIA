# 🐾 Huellas IA

## Plataforma inteligente para encontrar mascotas perdidas mediante Inteligencia Artificial.

## Objetivo

Crear una aplicación que permita conectar personas que perdieron mascotas con personas que las encontraron utilizando reconocimiento de imágenes mediante IA.

## Funciones principales

- Registro de usuarios
- Publicación de mascotas perdidas
- Publicación de mascotas encontradas
- Reconocimiento mediante IA
- Mapa de ubicaciones
- Notificaciones
- Chat entre usuarios

## Tecnologías

Frontend:
Flutter

Backend:
Python FastAPI

Base de datos:
PostgreSQL

Inteligencia Artificial:
PyTorch + Computer Vision
